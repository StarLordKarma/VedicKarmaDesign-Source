Postiz Local — Privacy Policy

Last updated: 27 October 2026. This policy describes the owner's private self-hosted instance, not the Postiz cloud service.

Information accessed

With the account holder's consent, the application accesses Google profile and email details, YouTube channel identity, video metadata, authorized performance metrics and permissions to upload and manage YouTube content. OAuth permissions may be broader than the features used routinely. Access is never used to sell user data or build advertising profiles.

Storage and use

OAuth credentials, connected-channel records, media and publishing records are stored in the owner's Postiz environment on external storage attached to the owner's Mac. The local application interface is bound to localhost. Google and YouTube process API requests as part of the requested publishing and analytics functions. Authorized operators may review content for preparation, scheduling and troubleshooting.

AI processing

The core publishing instance currently has no paid AI API provider configured. Separately and only as directed by the owner, content prompts and media may be processed through Codex or Meta AI. OAuth credentials and private analytics must not be included in those prompts. AI outputs are reviewed before use. Google API data is not used to develop or train generalized AI or machine-learning models.

Retention and deletion

Publishing records and source media are kept until the owner chooses to remove them. To disconnect, remove the channel in Postiz and revoke application access in the Google Account connections page. Revocation prevents future API access but does not automatically remove existing media or backups. Request deletion of locally retained data from the operator. Backups may retain earlier records until the owner removes or rotates them.

Limited Use

Postiz Local's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
