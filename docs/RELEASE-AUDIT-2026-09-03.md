# Проверка и подготовка независимого релиза — 03.09.2026

## Выполнено в рабочей ветке

- Проверены исходный todo, передача проекта Manus, спецификация Report Studio и roadmap.
- Исправлены единицы смещения часового пояса; добавлены исторические правила IANA,
  отклонение несуществующего/неоднозначного времени и неоднозначной географии.
- Сохраняются все настройки модели и лимитов генерации, а не только auto-process.
- Повторный платёжный callback восстанавливает пропущенное создание report job.
- Добавлены ограничения повторов расчёта и проверка изменения birth input после оплаты.
- Утверждение требует валидных расчётов и не допускается для synthetic jobs.
- Добавлены просмотр всех исходных фактов/разделов, контроль адресата и редактор
  текста с созданием новой PDF-версии и журналом изменения. Отправленная версия
  не редактируется; автоматическая отправка без утверждения не включена.
- Добавлены независимые OIDC, S3, LLM, Google Maps и Resend-подключения.
- Приватные ссылки и ключи файлов скрыты из HTTP-журнала, birth details убраны из
  уведомлений о новом заказе, debug/runtime Manus исключён из обычной сборки.
- Обновлены бренд, декоративная графика, типографика, фокус, reduced-motion и
  мобильные поля формы. Язык браузера учитывается при первом посещении.
- Добавлены Compose, HTTPS reverse proxy, проверки обязательной конфигурации,
  инструкции миграции, резервного копирования, восстановления и отката.
- Клиентская status-ссылка теперь даёт скачать только отправленную PDF-версию.
  Токен хранится только как SHA-256, проверяется повторно при каждом скачивании,
  прекращает работать после отзыва/истечения, а ключ хранилища клиенту не выдаётся.

## Проверки

- Полный Vitest: 176 passed, 12 skipped. Из пропущенных: 10 требуют тестовой MySQL,
  2 — настоящих внешних credentials и намеренно не выполняются автоматически.
- TypeScript: проверка без ошибок. Клиентская и серверная production-сборки прошли.
- Playwright/Chrome: главная, вход, dashboard и Report Studio на 1440 и 390 px;
  нет pageerror и горизонтального переполнения. Dashboard проверяется браузерными
  fixtures, не реальной сессией владельца. Скрипт ограничен localhost.
- HTML входной страницы после удаления platform-runtime: около 1.6 КБ вместо 368 КБ.
- Docker и MySQL integration добавлены в CI; локально Docker не установлен.
  Добавление workflow не означает, что удалённый CI уже успешно завершился.

## Условия допуска к production

1. Предоставить выбранный сервер, домен и безопасно настроенные credentials.
2. Пройти staging-проверки настоящего OIDC/MFA, S3, Maps, AI и email.
3. Выполнить миграции на отдельной тестовой базе и восстановление резервной копии.
4. Бесплатный путь зафиксирован как AGPL-3.0-or-later. До запуска необходимо сделать
   corresponding source точной production-версии доступным пользователям и заполнить
   `VITE_SOURCE_CODE_URL`; иначе требуется Professional License и новая проверка.
5. Проверить правомерность платёжной схемы для российского самозанятого, включая
   зарубежный счёт. Казахстанская карта не подключалась как эквайринг. Анонимность
   сторон не обещается; реальные платежи и массовые письма не запускались.

## Что не следует считать завершённым

Сам факт отметок в историческом todo не подтверждает production-приёмку. В частности,
не выполнены реальные внешние подключения, платёж/письмо на staging, восстановление
данных и deployment. Расширенный roadmap содержит дальнейшие улучшения: отдельные
причины изменений pricing/retention, полный retention-аудит, автоматическое сравнение
содержимого PDF. Выдача отчёта выполняется через email после owner approval, а
отправленная версия также доступна по активной отзываемой status-ссылке. История PDF-версий
доступна владельцу для ручного сравнения, но это не автоматический визуальный diff.
