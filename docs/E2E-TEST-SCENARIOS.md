# End-to-end сценарии sandbox

**Дата:** 2026-09-10

## Автоматизированный обязательный путь

`pnpm test:e2e` запускает Playwright (`e2e/sandbox.spec.ts`) и проверяет:

1. публичную форму заказа и обязательное согласие;
2. локальный checkout и подписанный payment callback;
3. sandbox owner-login и доступ к Report Studio;
4. calculation, LLM narrative и генерацию PDF;
5. review, approve, delivery и письмо с вложением;
6. формулировки о fiat privacy во всех четырёх локалях;
7. отказ во входе при неверном sandbox token.

Ожидается один завершённый delivered job, доступный PDF без раскрытия storage key,
а также отсутствие запросов к внешним сервисам.

## Ручные негативные сценарии

- повторить один IPN: статус/заказ не должны дублироваться;
- изменить подпись IPN: запрос должен быть отклонён;
- отозвать status token и дождаться expiry: скачивание должно быть запрещено;
- остановить mock/MinIO/MySQL по очереди: UI показывает безопасную ошибку, секреты
  и персональные данные не попадают в ответ/журнал;
- попытаться доставить synthetic/test job: сервер должен отказать;
- открыть `/admin` без owner session и с неправильным subject: доступа нет;
- проверить mobile/desktop RU/EN/DE/ES и PDF-шрифты.

## Астрологический benchmark

Автотесты фиксируют D1, D9, Lahiri ayanamsha, nakshatra/pada, Parashari full-sign
aspects и Vimshottari. Перед публичным запуском практикующий джйотиш-специалист
должен сравнить минимум 10 карт (включая границы знаков/накшатр, DST и разные
полушария) с признанным ПО, записать версию ephemeris, координаты и допуски.
Регрессионные fixtures не являются независимой сертификацией точности.
